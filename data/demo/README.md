# Demo data (fictional)

Harmless, made-up consulting notes for two demo engagements, used by
`scripts/seed_demo_data.py` for local screenshots and demos only:

- `meridian/`: Meridian Health (engagement id `meridian`)
- `kestrel/`: Kestrel Medical (engagement id `kestrel`)

Every organisation, person, number and result here is invented. Contact
details use the reserved `.example` domain and fictional numbers, and are
included so the redaction step has something to redact.
